# Blinkit_analysis_project
This project analyzes Blinkit grocery sales data using Python, SQL, and Power BI. It includes data cleaning, KPI calculation, and sales trend analysis across product categories and outlet tiers. An interactive dashboard was created to visualize revenue insights and support data-driven decision-making for retail performance evaluation.
Blinkit Sales Analysis Project
#Overview
This project analyzes Blinkit grocery sales data using Python, SQL, and visualization tools to extract business insights. It covers data cleaning, KPI calculation, trend analysis, and performance evaluation across outlets, item types, and sales categories.
The project demonstrates end-to-end data analytics skills suitable for real-world retail analysis.

# Key Insights
Low Fat products generated higher sales compared to Regular items.
Tier 3 outlets contributed the highest revenue.
Fruits & Vegetables and Snack Foods were top-performing categories.
Medium-sized outlets contributed the largest sales percentage.
